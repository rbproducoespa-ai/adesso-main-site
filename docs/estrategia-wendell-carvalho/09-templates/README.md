## Antes de usar qualquer um destes

Leia [`../08-riscos-e-conformidade.md`](../08-riscos-e-conformidade.md).

Três regras valem para **todos** os templates:

1. **Nada de promessa de renda.** Nem no gancho, nem no script, nem na sequência.
2. **O que você diz vira contrato** (CDC Art. 30). Alinhe palco = página = contrato, palavra por palavra.
3. **Só anuncie o que a sua operação entrega hoje** — não o que ela vai entregar quando crescer.
