# Roteiro de Reel — Template Operacional

## A estrutura de 40 segundos

```
┌──────────────────────────────────────────────────────────┐
│ 0,0 – 1,5s   GANCHO                    ← 90% do resultado│
│ 1,5 – 3,0s   TENSÃO                                      │
│ 3,0 – 25s    ENTREGA (1 ideia só)                        │
│ 25 – 35s     VIRADA (a frase repetível)                  │
│ 35 – 40s     LOOP                                        │
└──────────────────────────────────────────────────────────┘
```

---

## Template preenchível

```
TIPO:      [ ] Alcance  [ ] Conexão  [ ] Autoridade  [ ] Oferta
PADRÃO DE GANCHO: ____ (1 a 8, ver ganchos.md)
IDEIA ÚNICA: ______________________________________________

[0,0–1,5s] GANCHO
> ________________________________________________
  Enquadramento: rosto ocupando 60% da tela. Sem intro. Sem "oi gente".

[1,5–3,0s] TENSÃO — por que importa PARA QUEM ASSISTE
> ________________________________________________

[3,0–25s] ENTREGA — uma ideia, com exemplo concreto
> ________________________________________________
> ________________________________________________
  Corte a cada 3–4s. Mude enquadramento ou posição.

[25–35s] VIRADA — a frase que a pessoa vai repetir
> ________________________________________________

[35–40s] LOOP — emenda no gancho, ou pergunta que gera comentário
> ________________________________________________

LEGENDA: __________________________________________________
CTA:     [ ] Nenhum  [ ] "Comenta X"  [ ] "Salva"  [ ] Link (só em post de oferta)
```

## Regras técnicas que mudam o resultado

| Regra | Por quê |
|---|---|
| **Sem introdução.** O gancho é o frame 1 | "Oi gente, tudo bem?" custa 2s = metade da retenção |
| **Legenda queimada sempre** | ~70% assiste sem som |
| **Corte a cada 3–4s** | Reinicia a atenção antes que ela caia |
| **Vertical 9:16, rosto grande** | O rosto é o que segura a atenção |
| **Áudio limpo > imagem bonita** | Áudio ruim faz sair; imagem mediana não |
| **Primeira palavra forte** | "Nunca", "Pare", "Você", um número |
| **Loop perfeito** | O último frame emenda no primeiro → replays |
| **Nada de link no post de alcance** | Saída de plataforma derruba a entrega |

## Os 5 formatos que mais rendem

**1. Talking head puro** — você falando, cortes secos. O mais barato e o que mais escala. Comece por aqui.

**2. Cena + narração** — bastidor, viagem, rotina, com áudio gravado por cima. Alta conexão.

**3. Print/prova** — resultado de aluno na tela + sua narração. Alta autoridade. *Sempre com disclaimer de resultados* ([`../08-riscos-e-conformidade.md`](../08-riscos-e-conformidade.md)).

**4. Diálogo** — você e outra pessoa (sócio, cônjuge). Formato que o modelo do casal explora com força ✅ — ver [`../01-raio-x-do-modelo.md`](../01-raio-x-do-modelo.md).

**5. Resposta a comentário** — o comentário na tela, você responde. Gera mais comentários; alimenta o próximo vídeo em ciclo.

## Processo semanal de produção

```
SEGUNDA (3h) — bloco único de gravação
  30 min  escolher 10 ideias do banco (ganchos.md)
  30 min  escrever os 10 roteiros neste template
  90 min  gravar os 10, mesma roupa? NÃO — troque a cada 3
  30 min  enviar para edição / editar

TERÇA a DOMINGO (30 min/dia)
  publicar 1–2 reels + 5–10 stories
  responder TODOS os comentários da primeira hora
```

**Responder comentários na primeira hora é a alavanca de alcance mais subestimada.** O algoritmo lê velocidade de interação como sinal de qualidade — e a sua resposta gera a resposta da pessoa.

## Diagnóstico rápido

| Sintoma | Causa provável | Correção |
|---|---|---|
| Poucas views | Gancho fraco | Troque o padrão de gancho, não o tema |
| Views ok, retenção cai aos 5s | Entrega demora | Corte a introdução; vá direto |
| Retenção boa, poucos seguidores | Falta de motivo para seguir | Adicione a virada memorável |
| Muitos seguidores, poucos leads | Falta de conteúdo de oferta | Ajuste o mix para 10% oferta ([`../03`](../03-maquina-de-conteudo.md)) |
| Tudo bom, sem venda | Problema de oferta, não de conteúdo | Vá para [`../06-unit-economics.md`](../06-unit-economics.md) |
